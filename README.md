**Komp-presor PRO** is a high-performance, hardware-accelerated video compression utility wrapped in a desktop dashboard. Designed for speed and precision, it allows creators to drastically reduce video file sizes without sacrificing quality.

# <p align="center">🔥 Why Komp-presor? Coz it's free and runs locally unlike others that you will find online. It gives you lossless quality. 🔥</p>

*(Note: This repository serves as the official download hub and documentation page. The source code is closed and proprietary.)*

---

## ✨ Key Features

* **🚀 Hardware Acceleration:** Native support for NVIDIA GPU NVENC (H.265 / H.264) for lightning-fast render times.
* **🎯 Guaranteed Reduction Matrix:** Dial in your exact target file size (e.g., 60% of original) and the engine calculates the maximum allowable bitrate automatically.
* **⚡ Quick Load:** Paste a file path directly into the smart search bar to instantly analyze video metadata (Codec, Bitrate, Resolution).
* **💼 Fully Portable:** No installation required. Just extract the folder and run the `.exe`.

## 📥 How to Download & Run

Because this is proprietary software, you do not need to clone this repository. Follow these steps to get the app:

1. Navigate to the **[Releases](../../releases)** tab on the right side of this page.
2. Under the latest version (v1.0), download the **`Komp-presor_v1.0_Windows.zip`** file.
3. Extract the `.zip` file to your desired location on your PC.
4. Open the extracted folder and double-click **`Komp-presor.exe`** to launch the dashboard.

*(Requires Windows 10 or 11. FFmpeg engines are fully bundled within the download.)*
